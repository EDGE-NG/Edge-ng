# Database migrations

SQL migrations for the Supabase (PostgreSQL) database. Owner: Sheyi.

Tables, rules and indexes follow PRD section 9 (9.2 design rules, 9.3 tables, 9.5 integrity rules). Name files in order, e.g. `0001_identity.sql`, `0002_checklists.sql`. Never edit a migration that has already been applied; add a new one.
